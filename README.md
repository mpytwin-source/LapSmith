# LapSmith Motorsport Simulator

LapSmith is a Python-based motorsport simulation and telemetry analysis project designed to explore how vehicle setup changes affect performance around a circuit.

The goal is to create an interactive engineering sandbox where users can choose a vehicle, modify its setup, simulate a lap, and analyze the resulting telemetry.

## Current Features

- GT, Formula, Hyper Car, and Stock Car vehicle types
- Adjustable rear wing settings
- Aerodynamic drag simulation
- Downforce simulation
- Tire grip and traction limits
- Acceleration and braking simulation
- Corner speed calculations
- Full track simulation using straights and corners
- Lap time calculation
- Telemetry recording
- Speed vs. distance telemetry graphs

## Physics Model

LapSmith currently models:

- Engine power
- Drivetrain efficiency
- Aerodynamic drag
- Aerodynamic downforce
- Tire grip
- Longitudinal acceleration
- Braking
- Cornering forces

The current physics model is simplified for development and experimentation. Vehicle parameters are educational approximations rather than validated manufacturer specifications.
